Put your SMIC club logo here.

Save the bull "SMIC" logo image as:

    smic-logo.png

in THIS folder (web/frontend/public/). The app loads it at "/smic-logo.png"
for the header logo and the browser tab icon.

PNG is recommended (transparent background looks best), but a .jpg works too
if you also update the <img src> / favicon references to match the extension.

Until this file exists, the app automatically falls back to the green tile
with the chart icon — so nothing breaks.
